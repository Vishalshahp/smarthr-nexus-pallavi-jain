SMARTHR NEXUS - HOW TO RUN

Start:  double-click "START SmartHR.bat" in this folder.
        The first start installs packages and adds demo data (a few minutes).
        The website opens at http://localhost:3000

Stop:   close the window titled "SmartHR servers".

AI features (ARIA chat, resume screening) need a Google Gemini API key
(free at https://aistudio.google.com/app/apikey). Put it in:
  backend\.env   ->  GEMINI_API_KEY=your-key
  frontend\.env  ->  VITE_GEMINI_API_KEY=your-key
then close the "SmartHR servers" window and start again.

Reset demo data: delete backend\.demo-data-added and start again.
